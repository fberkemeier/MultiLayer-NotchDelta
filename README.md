# Multi-layer Signalling Model (MSM)

Repository for wing disc signalling simulations, analysis, and figure generation.

## Project structure

- `src/msm_model.py`: Core model and analysis/plotting functions.
- `notebooks/msm_notebook.ipynb`: Main interactive workflow and examples.
- `data/`: Input datasets (geometry, adjacency matrices, spacing-analysis files).
- `figures/`: Output figures generated by the analysis code.
- `.github/workflows/run-script.yml`: CI smoke test for environment/module import.

## Quick start

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

## Run the notebook

```powershell
jupyter notebook notebooks/msm_notebook.ipynb
```

The notebook prepends `../src` to `sys.path` and imports:

```python
from msm_model import *
```

## Use from scripts

```powershell
$env:PYTHONPATH="src"
python -c "import msm_model; print('ok')"
```

## Notes

- Keep `data/` at repository root; `msm_model.py` reads relative paths from there.
- Figures are written to `figures/`.
- Some analyses write text outputs under `data/sensitivity_analysis/`.
