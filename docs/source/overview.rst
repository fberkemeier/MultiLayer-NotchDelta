Overview
========

What this project does
----------------------

This repository implements a Multi-layer Signalling Model (MSM) for Notch-Delta dynamics in epithelial tissues.
It combines depth-resolved adjacency data, cell geometry, and region metadata to run simulations and quantify patterning outputs.

Main components
---------------

- ``src/msm_model.py``: core model and data-loading functions.
- ``notebooks/msm_notebook.ipynb``: main user workflow and analysis notebook.
- ``data/``: region inputs (adjacency matrices, cell geometry, metadata).
- ``figures/``: generated output plots.
